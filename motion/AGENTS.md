# Instruções para continuar este projeto

Leia primeiro `CONTEXTO.md`, `README.md` e `STATUS.md` nesta pasta. O usuário quer
um motion design pessoal feito pelo assistente, não um app, editor ou plataforma.

- Falar em português brasileiro, com clareza e poucas palavras.
- Trabalhar autonomamente dentro do escopo autorizado. Não pedir ao usuário para programar.
- Não contratar, pagar, provisionar serviço pago ou usar APIs que cobrem.
- Fish Audio e clonagem de voz foram explicitamente retirados do escopo.
- Preservar o site existente e a branch main. Trabalhar na branch motion-pessoal.
- Não publicar áudios pessoais, transcrições sensíveis ou amostras de voz automaticamente.
  Informar que a branch/repositório de teste é público antes de enviar mídia do usuário.
- O áudio original deve guiar a narrativa e os pontos de entrada dos elementos.
- Não inventar dados em gráficos. Não chamar regras de IA ou simular transcrição.
- Adaptar cenas ao assunto: a biblioteca é um ponto de partida, não uma montagem
  genérica que substitui o conteúdo por frases arbitrárias.
- Conferir dependências com `npm ci`, `npm run check`, `npm test`.
- Renderizar e executar `npm run verify` antes de afirmar que um vídeo está pronto.
- Diferenciar renderização local, código publicado e renderização comprovada no Actions.
- Atualizar `STATUS.md` e `CONTEXTO.md` com testes reais e o próximo passo.
- Não garantir memória global entre conversas: estes arquivos são a fonte durável.
